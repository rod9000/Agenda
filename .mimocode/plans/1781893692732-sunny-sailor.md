# Fase 8 — Integração Evolution API (WhatsApp)

## Contexto

O projeto **AgendaBarbearia** (`C:\Users\Precode TI\Documents\GitHub\AgendaBarbearia`) possui integração completa com a Evolution API para WhatsApp. A **Agenda Estética** possui apenas um `WhatsAppService` básico que lê de `config/services.php`. A adaptação considera que a Agenda Estética é single-tenant (sem modelo `Company`).

## Plano de Implementação

### 1. Migration — criar tabela `companies`

**Criar:** `database/migrations/2026_06_19_000001_create_companies_table.php`

Consolidar todas as migrations do AgendaBarbearia em uma única migration:

```php
Schema::create('companies', function (Blueprint $table) {
    $table->id();
    $table->string('name');
    $table->string('slug')->unique();
    $table->string('email')->nullable();
    $table->string('phone')->nullable();
    $table->string('whatsapp', 20)->nullable();
    $table->string('cnpj')->nullable();
    // Evolution API
    $table->string('evolution_api_url')->nullable();
    $table->string('evolution_api_key')->nullable();
    $table->string('evolution_instance_name')->nullable();
    $table->string('whatsapp_type')->default('normal');
    // Bot/Webhook
    $table->boolean('webhook_enabled')->default(true);
    $table->boolean('bot_enabled')->default(true);
    $table->text('welcome_message')->nullable();
    $table->text('off_hours_message')->nullable();
    $table->string('evolution_webhook_url')->nullable();
    // Trial
    $table->timestamp('trial_starts_at')->nullable();
    $table->timestamp('trial_ends_at')->nullable();
    $table->boolean('active')->default(true);
    $table->timestamps();
});
```
